## 1. Project Title

**jerrick-resume**

## 2. Project Overview

This project is a responsive online resume website built using only HTML, CSS, and JavaScript.

It was created as part of a learning journey in web development and professional portfolio building.

### Why this project is useful

- Beginner-friendly code structure for students
- No frameworks, only core web technologies
- ATS-friendly content layout and headings
- Print-friendly styling for resume export and sharing
- Suitable for students and beginner developers applying for internships

## 10. GitHub Pages Deployment

Follow these steps to publish the website:

1. Push your code to GitHub.
2. Open your repository on GitHub.
3. Go to **Settings**.
4. Click **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save**.
8. Wait for deployment, then open the generated live URL.

## 11. Local Development

To run this project on your computer:

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Edit `index.html`, `style.css`, and `script.js` to continue learning and improving the site.
